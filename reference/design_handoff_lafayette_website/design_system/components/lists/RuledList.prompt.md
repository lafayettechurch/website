Rows separated by 1px warm rules, each with a Fraunces title and body — for core values, beliefs, a Sunday schedule or step-by-step directions.

```jsx
<RuledList numbered items={[
  { title: 'Scripture', body: 'We read the Bible together and let it shape our life.' },
  { title: 'Family', body: 'A loving family called by God.' },
]} />
<RuledList layout="stacked" items={[{ numeral: '9 AM', title: 'Bible classes', body: 'For all ages.' }]} />
```

- Use `stacked` below ~640px. Keep bodies to 1–2 sentences.
